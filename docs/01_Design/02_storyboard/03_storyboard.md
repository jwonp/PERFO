# PERFO 서비스 화면 구성 및 플로우 분석

스토리보드 이미지(`01_Perfo.png`) 기반으로 분석한 PERFO 서비스의 전체 화면 구성과 페이지별 주요 요소입니다. 전체 서비스는 크게 **랜딩, 인증(로그인/회원가입), 메인 서비스(바텀 내비게이션 기반 3개 탭)** 영역으로 구분됩니다.

---

## 1. 랜딩 페이지 (Landing Page)
- **목적**: 서비스 첫 진입 시 신규 사용자를 맞이하고 서비스를 소개
- **특징**: 로그인된 사용자는 랜딩 페이지를 볼 수 없도록 처리 (접근 방지)
- **화면 구성 요소**:
  - 서비스 로고
  - 서비스 소개 문구
  - `Get Started` 버튼 (클릭 시 로그인/가입 화면으로 리다이렉트)

---

## 2. 로그인 · 회원가입 (Authentication)
이메일 및 소셜 로그인을 통합하여 하나의 시작점에서 분기되는 방식입니다.

### 2.1 이메일 입력 및 소셜 로그인 메인 (진입점)
- 최상단 PERFO 로고 및 로그인 유도 문구
- 이메일 입력창 + `다음` 버튼 (입력된 이메일의 가입 여부에 따라 다음 화면 분기)
- 소셜 로그인 옵션 (버튼 및 라벨: 구글, 카카오, 라인, 네이버)

### 2.2 비밀번호 입력 (기존 가입 이메일인 경우)
- 뒤로 가기 버튼 / PERFO 로고
- "{이메일}로 로그인" 환영 문구
- 비밀번호 찾기 링크
- 비밀번호 입력창 (비밀번호 보이기/숨기기 토글 버튼 포함)
- `로그인` 버튼

### 2.3 회원가입 (신규 이메일인 경우)
- 뒤로 가기 버튼 / PERFO 로고
- "{이메일}로 회원가입" 문구
- 새 비밀번호 입력창 (보이기/숨기기 토글)
- **비밀번호 유효성 검사 체크 UI (실시간 피드백)**:
  - 8자 이상, 영문 포함, 숫자 포함, 특수 문자 포함
- 이용약관 안내 링크
- `회원가입` 버튼

### 2.4 비밀번호 초기화 플로우 (비밀번호 찾기)
1. **[비밀번호 초기화 전 본인 인증]**
   - "{이메일}으로 본인 확인용 6자리 인증번호 발송" 문구 노출
   - 6자리 인증번호 입력창
   - `번호 확인` 버튼 및 `재전송` 버튼
2. **[비밀번호 초기화]**
   - "{이메일}에 대한 비밀번호 초기화" 문구
   - 새로운 비밀번호 입력창, 비밀번호 확인 입력창 (보이기/숨기기 토글)
   - 위 2.3과 동일한 비밀번호 유효성 검사 체크 UI
   - `비밀번호 초기화` 버튼
3. **[비밀번호 변경 완료]**
   - 비밀번호 변경이 성공적으로 완료되었음을 알리는 안내 UI
   - `로그인 페이지로 돌아가기` 버튼

## 3. 메인 서비스 (로그인 후 진입)
로그인 후에는 하단에 **바텀 내비게이션(예약한 티켓 / 내가 발급한 티켓 / 유저 정보)**이 기본으로 배치되어 각 메뉴로 이동할 수 있습니다.

### 3.1 예약한 티켓 탭 (일반 사용자 모드)
내가 애매하거나 보유중인 티켓들을 확인하고 실제로 사용하는 메뉴입니다.

- **예약한 티켓 리스트 (메인)**
  - 상단: 타이틀, 검색 버튼, 알림 표출 버튼
  - 필터링: "사용한 티켓만 표시" 토글 버튼
  - 리스트 뷰: 무한 스크롤로 티켓 로딩
  - 리스트 아이템 구성 (티켓 배경 이미지 포함):
    - 상태(사용 전, 순서 대기중, 현재 순서임, 사용 완료)
    - 티켓 이름, 티켓 번호, 사용장소, 유효날짜
    - QR 표시 버튼
- **예약한 티켓 상세 - 사용 전**
  - 티켓 배경 이미지와 함께 기본 정보(아이템 구성과 동일) 강조
  - **입장 검표를 위한 QR 이미지** 활성화 표시
- **예약한 티켓 상세 - 사용 후**
  - 사용 전 티켓과 화면구성이 유사하나,
  - '사용 완료 상태'로 전환되며 실제 **사용한 날짜와 사용완료 문구**가 명시됨

### 3.2 내가 발급한 티켓 탭 (운영자 / 주최자 모드)
주최자 입장에서 발급한 티켓들을 관리하고 검표(QR 스캔)하는 메뉴입니다.

- **내가 발급한 티켓 리스트**
  - 상단: 타이틀, 검색, 알림 표출 버튼
  - 리스트 뷰: 무한 스크롤
  - 리스트 아이템 요약 정보:
    - 티켓 상태 (티켓 발급중, 비활성화, 기간만료, 티켓 검표중 등)
    - 티켓 이름, 사용장소, 유효날짜
    - (발급된 티켓 수 / 전체 티켓 수) 통계 노출
- **티켓 검표 화면 (카메라 연동)**
  - 뒤로 가기 버튼, 티켓 이름
  - 순서대로 입장하는 행사일 경우 "현재 순서 번호" 안내 기능
  - 중앙의 뷰파인더 뷰: **QR 스캔을 위한 카메라 화면 영역**
  - 스캔 결과에 따른 "(티켓 번호)번 티켓 정상 확인 문구" 또는 "확인 실패 문구" 노출

### 3.3 유저 정보 탭 (마이페이지)
사용자 개인정보 관리와 앱 설정, 고객지원을 담당합니다.

- **유저 정보 메인 (목록)**
  - **프로필**: 유저 아이콘, 유저 이름 (수정 버튼 포함), 유저 아이디 노출
  - **APP SETTINGS (앱 설정 영역)**
    - 다크 모드 설정 토글 버튼
    - 푸시 알림 설정 토글 버튼
  - **SUPPORT (고객 지원 영역)**
    - 고객 문의 탭 (클릭 시 이동)
    - Privacy Policy (개인정보처리방침) 탭 (클릭 시 이동)
  - 가장 하단에 **로그아웃 버튼** 배치
